# Sigrun

Sigrun — victory over key chaos.

Sigrun is a cross-platform SSH key and connection manager. It stores your SSH
keys and connection profiles in an encrypted local vault, generates new keys,
syncs public keys to hosts over SSH, and launches connections — replacing
scattered `~/.ssh` bookkeeping with one tool that works the same on macOS,
Linux, and Windows.

```bash
cargo run -p sigrun-cli -- --help
```
